# CaseLink

面向 TrialWatch 内部倡议人员与法律研究人员的表达案件研究原型。合作当地律师、NGO 案件协调人、媒体法务与安全编辑也可使用。工作范围包括由新闻、发言、发帖或其他表达活动引发的刑事追诉、拘押、诽谤或 SLAPP 风险、出境限制、平台与行政处罚。

本轮定位是：**正式案例库为主干，国际标准与机制提供有适用条件的依据，公开网页补充明确待核实**。一般纠纷不进入完整付费研究；表达关联不清楚时先确认。项目是独立原型，不声称获得 TrialWatch 官方认可。

本地代码已按 2026-10-09 迭代说明开发，尚未发布本轮代码。生产站点仍是 [caselink-eight.vercel.app](https://caselink-eight.vercel.app) 的此前部署。完整交付与真实验证范围见 [本轮验收](docs/iteration-2026-10-09/acceptance.md)，部署核对见 [准备记录](docs/iteration-2026-10-09/preflight.md)。旧版文档中的“通用纠纷、联网主干、自动补查、自动保存”描述不适用于本轮代码。

## 本地运行

Node.js 24 与 npm，依赖只安装在项目内：

```sh
cd /Users/fenghao/Desktop/hackhaton/caselink

```

打开 `http://127.0.0.1:3000`。明确指定 demo 可覆盖已有 `.env.local` 的 live 设置；演示与规则模式不调用模型。

```sh

npm run build
ANALYSIS_MODE=demo npm start
```

本机附带运行时：`/Users/fenghao/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin`。构建沿用 webpack 配置；不迁移项目、不修改全局运行时。早期 `../caselink-v1-classic` 与 `../caselink-v2-modern` 继续保留。

## 功能入口

| 路径 | 用途 |
| --- | --- |
| `/new` | 自由案情、法域确认、表达关联、动态事实补问及人工确认；`?mode=classic` 提供逐题视图。两种视图共享完整案情。 |
| `/review` | 核对案情、目标和披露限制；AI 开关与保存偏好独立于事实。 |
| `/analysis` | 正式库比较、行动材料建议、来源与限制；手动发起补查、主动保存、快照导出。 |
| `/history` | 仅主动保存的本浏览器报告；到期清理、删除、可恢复备份及旧文件导入。 |
| `/cases` | 22 个公开案件及原文、页码、历史行动、结果与冲突。 |
| `/compare` | 选择 2–4 个公开案例，并排比较、共同主题、差异、未知项、固定快照及交接简报导出。 |
| `/resources` | 国际条约、解释文件、机制与援助机构，分别显示适用条件和审核状态。 |

主页提供记者拘押、博主表达处罚风险、英国民事诽谤或 SLAPP 风险三类**虚构**输入。英国演示用于展示具体法域确认及正式库覆盖不足，不承诺找到英国可比案例。规则模式、预置演示、实时模型结果分别标识，不能互称。操作路径见 [研究工作区与演示](docs/iteration-2026-10-09/research-workspace.md)。

## 隐私与历史

新工作流程默认只在内存保存案情和结果；不自动写入 localStorage 或 IndexedDB。AI 是否启用不会清空案情、目标或披露限制。用户主动保存某一报告后，才在本浏览器 localStorage 留存；可选 1、7、30 天有效期。刷新恢复是另一项明确同意，在本标签页 sessionStorage 保存最多 24 小时。新建案件回到默认设置。浏览器清除网站数据会影响已保存资料。

旧版自动保存数据不静默删除或迁移；界面提供明确的恢复与清理入口。删除旧报告不清空正在编辑的新草稿。跨标签页删除标记只保留不含原始案情的标识。未保存内容刷新会丢失，应按实际需要选择保存或下载。

新报告固定生成时的案例、引文、文档、资源与网页资料。历史页面、证据弹窗和导出读取同一快照。旧报告没有的内容显示限制，不从今天的库补成当时记录。JSON 备份与导入统一使用字节和条目上限，过大的备份拆分或明确阻止；下载文件的保管期限由用户管理。

付费请求为幂等重试在服务端暂存**会话绑定的加密结果，最长 120 秒**；这是服务处理所需的短期留存，不是云端历史报告。匿名用量会话与不含案情的计数/请求摘要另有短期有效期，见用量说明。没有账号、跨设备同步或复杂团队协作。

## 研究与成本边界

- 服务端在付费前校验表达关联。明确无关则停止完整研究；信息不足则要求确认。三个英国法域使用 `GB` 与同一规范枚举；更换国家不会继续采用旧英国法域。
- 默认仅一轮研究。用户主动点击补查才创建新的操作与请求标识；不得在没有结果时自动补搜。一次研究内部至多两条受控搜索查询和一次模型综合，案情整理是独立付费入口。
- 自动的 OpenAI 自主搜索已移出执行路径。可选 Brave Search 接口只收到服务端固定词表组成的字面查询；原始案情、姓名和自由叙述不进入搜索查询。完整案情仍会在用户启用 AI 时发给无搜索工具的整理/综合模型。
- 本轮搜索仅获取结果片段，**没有打开原文全文**。网页候选与查询会保留来源标识及未核实状态。外部搜索商内部如何检索不可由本应用证明；实际 provider 集成仍须验收。
- 缺少受控搜索配置时可使用案例库，自动联网关闭。缺少分布式用量保护或价格配置时，所有付费入口失败关闭，规则参考仍可用。
- Redis REST 原子脚本实现会话/IP 日限额、全局日预算预留、并发和幂等；计入在途请求与最坏成本。相同会话/请求/输入可去重，同标识不同输入拒绝。未知 provider 成本保留全部预留。模拟验证不等于生产生效。
- 记录阶段耗时、模型与 token/工具用量、失败阶段，不记录原始案情日志。没有后端实时事件时仅显示处理中，不用计时动画冒充研究阶段。

本轮保留既有模型配置，不以换模型替代边界修复。`.env.example` 和 B 的 [研究与用量说明](docs/research-usage.md) 列出配置。不要把密钥放聊天、源码或提交。生产未见 Redis/受控搜索等必要新配置，OpenAI 账户支出提醒和硬限制也尚未核验；不能宣称生产用量控制已经生效。

## 资料与审核

实际盘点：22 案、14 个国家或地区、21 份文档、804 页、187 条引文。182 条保留原 `verified` 标签，5 条保留冲突；不代表本轮完成具名团队人工审核、原案独立调查或全部原文精读。文档与原始页码没有因程序测试通过而升级审核状态。

国际资源层有 16 条，其中 15 条完成 agent 来源检查、1 条待核实；全部仍待团队人工复核。原有两条的说明与检查日期保留。官方链接不代表机构必然接案，国际标准不自动成为当地可直接适用法律。详见 [资源审核清单](docs/iteration-2026-10-09/resource-review-checklist.md) 和 [数据盘点](docs/iteration-2026-10-09/corpus-resource-inventory.json)。

多案比較只归纳选定案例中记载的现象，不推断国家发生率，不把行动与结果的时间先后写成因果。缺失的结构化法域、程序类型、罪名等保持“未记载”。一般材料整理建议明确是建议。

原始资料不加入 public；运行时只读已整理 JSON。`scripts/extract_pdfs.py` 与 `scripts/check_evidence.py` 用于开发阶段提取和核对，`node scripts/research-inventory.mjs` 重跑数量盘点。
