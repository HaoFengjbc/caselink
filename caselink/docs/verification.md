## 浏览器错误与请求竞态

独立脚本保存在 `scripts/qa-review*.mjs`，以本地模拟分析响应测试，不会调用付费模型：同一tick双击只有一次请求；取消后旧响应晚到无效；新的有效响应落盘；离开确认页后晚到无效；刷新不重复分析；授权过期重新显示解锁；服务状态未知仍告知可能调用AI并提供显式规则入口；可恢复失败同一输入最多恢复重试一次，保留requestId；拒绝不提供重试；近似日期保留标识。可在服务启动后执行 `npm run test:browser-guards`。
