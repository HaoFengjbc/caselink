1. 配置共享 Redis REST、服务端随机 secret、可信代理 IP header、逐模型审核价格、日预算/限额，之后再执行真实多实例、故障和到期验证。代码中的原子脚本不是已连接生产 Redis 的证明。
2. 如需联网，配置 Brave Search key 和该账户每次查询最大成本，再测试实际 outbound q、provider 返回及费用。当前只读取搜索结果片段，`pageOpened: false`；**未实现完整网页阅读器**。
3. OpenAI 项目模型权限、实际返回型号、价格、账户支出提醒与硬上限仍需分别核对。本轮没有输出或复制密钥，没有绕过用量门槛。

5. 既有案件没有统一的具体法域、程序类型、罪名、审核人/日期字段；没有让模型补齐。英国正式库覆盖为零。来源事实只截至各报告时期。
6. 项目源码许可证及第三方摘录/翻译再分发范围未获完整确认，本轮未替项目选许可。

## 团队演示路径

- `ANALYSIS_MODE=demo npm run dev` → `/` → 虚构示例 → 核对案情及内部披露限制 → 规则参考 → 原文弹窗 → 主动保存 → `/history`。
- `/new` → 输入长虚构叙述 → 切换逐题/自由视图 → 内容保留；不选择保存时刷新应丢失。单独同意刷新恢复后重试。
- `/compare` → 选 Aigul Utepova、Emna Chargui → 生成 → 展开日期冲突原文 → 差异/未知 → Markdown/JSON 导出 → 打开 JSON。
- `/resources` → 类型筛选 → 查看官方定位、适用条件、agent/team 审核分别显示。
- 英国虚构示例 → 分别确认英格兰和威尔士/苏格兰/北爱尔兰 → 查看 GB 与对应法域，理解本国正式库覆盖不足。
