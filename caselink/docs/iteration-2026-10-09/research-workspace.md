# CaseLink 专业研究工作区：内容、比较与演示

## 比较工作区

`/compare` 选择 2–4 个公开案例，点击“生成比较快照”。八行固定字段展示国家/法域、表达活动、程序、指控或争点、程序问题、历史行动、后续状态、未知项。缺少标准化字段时显示“未记载”，已有摘要与程序记录另行展示；不调用模型补齐。每组既有事实可展开原文引文、文档标题、物理页与印刷页。网页打印页不伪装成官方 PDF 跳页。

共同问题部分仅归纳所选案例已有问题标签，列支持案件、原始证据、各案后续状态差异和未知项。它不输出国家发生率、胜诉率或倡议效果归因。历史行动的 `executionStatus` 与 `relationshipToOutcome` 原样保留，建议不会被列成已实施行动。内部交接准备是工作建议，不附不相关法条冒充依据。

比较的事实与来源由 A 的 `captureCaseSnapshot` 固定到统一 `ComparisonBrief`。组件 `ComparisonBriefView({brief})` 与 `EvidenceLayers({snapshot})` 只读传入快照，不按 ID 回查当前案例库。当前资源在生成时加入快照；以后资源更新不会改写现有简报。Markdown 导出调用 A 的统一 `comparisonMarkdown`，JSON 导出可恢复整个快照。导入与导出同用 3,000,000 字节上限，超限明确阻止导出；导入检查案件归属及共同问题证据引用。

默认仅页面内存，刷新或离开页面会丢失尚未导出的比较。用户主动下载后，文件保存在其下载位置，由用户管理；没有自动写 localStorage、没有云端或账号存储。导入 JSON 是提供者保存的内容，无签名认证。不要把导入文件当重新人工核实的官方事实。

## 三层依据

- 正式案例库：保留原报告、页码、引文审核记录和冲突，说明事实截至日期。
- 国际标准与资源：`/resources` 显示 16 条记录，按条约、解释文件、联合国机制、区域机制、援助机构分类。每条独立显示检查日期、团队审核状态、条件、未知项与官方来源。15 条 agent 检查，1 条全文访问受阻而待核实；全部尚未团队人工复核。原有两条日期及说明保留。
- 公开网页：没有自动进入正式库；在报告快照中归为待核实补充。打开网页、拿到链接不等于每句事实正确。一般材料整理建议另标建议。

资源目录没有根据用户国家自动宣布适用。ICCPR 缔约与保留、欧洲公约管辖范围、国内救济与申请条件、援助机构是否接案，都应由案件负责人与当地律师核对。没有计算诉讼期限或承诺结果。

## 三类虚构演示

`data/demo/fixtures.ts` 的中英文数组各有三个虚构场景。它们不写入真实案例库，也不捏造真实判决或期限。

1. **记者刑事/拘押**：哈萨克斯坦调查记者候审拘押、有律师、先内部处理。演示问题标签、历史行动及未知因果关系。原日期字段是虚构待确认的计划，不能作为法律期限。
2. **博主表达处罚风险**：突尼斯博主因转发讽刺内容受审并收到威胁。演示表达关联、公开意愿与案例差异，不声称已取得终局判决。
3. **英国民事诽谤 / SLAPP 风险**：英格兰和威尔士调查记者收到律师函，没有法院文件。是否 SLAPP 明确待当地律师核实；只内部研究。演示 `GB / england_wales`、民事程序与英国正式库覆盖为零，不承诺本国可比案例。国家切换、服务端领域确认由 A/B 负责。

规则演示路径：主页 → 选择虚构示例 → 核对事实和披露限制 → 规则参考。若示例显示待确认，先人工核对再继续；修改输入后的结果不宣称是原封不动的预置演示。多案路径：`/compare` → 选择 Aigul Utepova 与 Emna Chargui → 生成 → 展开原文 → 查看差异与未知 → 导出 Markdown 和 JSON → 重新打开 JSON。

本 C 分支没有真实 AI 请求，也没有录制 AI 回放。今后如使用主负责人取得的录制结果，须标注录制时间、代码/语料版本、虚构输入、当时实际模式以及“回放，非现场请求”。不能将规则或录制结果标成实时 AI。
