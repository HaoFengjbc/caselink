# 两分钟演示脚本

先使用本地或已验证的预览地址。默认演示模式无需密钥。开始前确认首页显示3个真实历史案例；示例新案为虚构，不计入案例库。以下是操作脚本，不是已经实测通过的声明；实测结果见验收记录。

## 0:00—0:20：说明价值并载入示例

讲述：“CaseLink 从少量可核对的历史材料中，整理下一步可以考虑的行动。它帮助比较条件，不预测胜诉。”

点击首页“体验示例案件”，选择“博主被诉：考虑公开倡导”，再点“载入示例并查看案情”。展示其虚构标识、突尼斯、审判阶段，以及“争取停止起诉”的主要目标。公开限制为“可以考虑公开”。

## 0:20—0:40：确认后才分析

载入后直接到确认页，让观众看到案情摘要与未知项。“这一步才提交分析；浏览题目或刷新不会自动发起付费请求。”

先看确认页显示的模式。生产站点当前配置为实时AI，直接点击“查找案例并生成行动参考”，无需密码。

本地默认演示配置则展示预置演示模式，明确说明“未调用实时AI”。若调整了示例字段，在演示配置下应成为规则参考，不把任意输入都冒充固定预置结果。任何模式都可以明确选择“改用规则参考 · 不调用 AI”。

## 0:40—1:05：核对一个历史事实

查看 Myriam Bribri 或 Emna Chargui 的比较。点开证据：英文摘录、中文解释、PDF页码、印刷页码以及报告日期。

讲述：“Myriam律师申请更多准备时间后听证延期，这不是已经撤诉。Emna报告内部的宣判日期有冲突，系统保留两条原文；获得德国庇护也不等于定罪被撤销。”

## 1:05—1:30：展开一项行动

展开当前行动参考，依次指出目标、牵头角色、前置条件、时机、执行步骤、材料、协作者和跟进点。说明哪些来自历史事实，哪些是针对当前虚构案件的建议，哪些仍待核实。

如果出现机构入口，指出那是当前已核查的官方页面；历史报告建议邀请特别报告员国别访问，不等于特别报告员已办理此案，也不等于当前承诺受理。

## 1:30—1:50：改变限制，看输出变化

在结果页的公开限制区域点“修改限制”，选择“希望先保持私下处理”，然后回到确认重新分析。观察旧结果过期提示，完成后核对公开传播类选项转为条件性或暂缓，理由与前置条件随之变化。

讲述：“建议随目标和实际限制调整；公开传播不是默认立即执行的动作。”

## 1:50—2:00：带走可追溯结果

使用复制方案或下载Markdown。检查导出包含生成模式、来源、报告时点、未知项与限制。浏览器打印可另存为PDF；不要说系统已生成不存在的PDF文件。

## 第二场景与备用路径

- 选择“记者受限：先私下争取释放”，说明Aigul精神医疗措施调整是部分变化，出院没有解除所有人身限制。切换主要目标为“获得律师帮助”再分析，对比步骤和材料如何改变。
- 没有实时模型配置时正常演示规则参考，不把它称为实时AI。
- 实时模式出现配置、限流、超时或拒绝错误时，指出错误状态；只有用户明确选择规则参考后才展示对应模式。
- 某筛选没有结果时展示空状态，说明首版仅有三个主案；不声称没有相关历史案例存在。
- 正式演示前按README启动生产模式、检查完整流程、移动端和导出。关闭浏览器会话后不承诺恢复历史。
