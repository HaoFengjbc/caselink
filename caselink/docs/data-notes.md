## 证据处理

`scripts/extract_pdfs.py` 按文件内容 SHA-256 去重，每份独立报告按物理 PDF 页提取。全文提取只在开发离线运行，网站不调用 Python、不反复解析 PDF。空白归一化保留英文原词、标点及文本层脚注标识；它不修正原报告的拼写或日期。`exactQuote` 为报告中的实际短段落，非需求文档摘要翻译。

编者对纳入的案情、行动、结果和建议段落进行语义对照。首批特别复核以下原始页面图像：Aigul PDF22/27/32；Emna PDF12/14/15/34；Myriam PDF7/8/16。其他已纳入摘录根据逐页文本及邻接上下文核对。`reviewStatus=verified` 表示本项目核对了报告记载，不表示对报告所述事件另行调查或取得原审卷宗。正文引用脚注的内容仍仅作为原报告记载；脚注里的法院材料、新闻、其他案例未因此自动变成独立核实来源。首批三份报告的印刷页码为物理页码减1；这一偏移不套用于新增报告。物理页码逐条记录，印刷页码不能确定时为null。Dian Abdullah来源是ABA网页打印件（`sourceFormat=web_print`），其归档页码不冒充官方出版页码，链接指向官方网页而不加PDF跳页参数。

首批`check_evidence.py`核查32条摘录；扩展入库后，同页归一化原文、文档哈希、实际页码、案件归属及来源URL检查覆盖当前187条引文。入库脚本还重新计算本地源文件哈希。字符串命中只能发现引用位置或转录问题，不能代替上述语义阅读。`scripts/data.test.ts`随Vitest运行Zod schema、唯一ID、同案结果引用、身份、日期冲突及材料建议分离等检查；`tests/expanded-corpus.test.ts`补充共享来源、同人不同程序、中英文地区、候选数量与完整结果引用边界。

## 当前资源与历史参与分开

[OHCHR特别程序提交指引](https://spsubmission.ohchr.org/)与[CPJ记者安全及紧急协助](https://cpj.org/journalist-safety-and-emergencies/)于2026-10-07核对。资源记录只提供官方入口、适用范围及准备要求，不表示其历史上办理过库中所有案件，也不表示当前承诺受理。

OHCHR指引要求可信具体的说明与关键佐证，并要求关注披露同意；自动回执不是专家已采取行动。报告建议国家邀请国别访问，与个人向特别程序提供信息是不同途径。普通 communications 介绍页抓取返回403，本项目改用已实际读取的官方提交指引页面，没有把403页面写成已核实内容。

CPJ当前说明面向因新闻工作遭遇相关事件的记者和媒体工作者，按个案评估紧急支持。博主或活动人士必须另行核实是否属于其援助范围，不能自动当成记者；页面也不保证回应或资助。没有复制未核实的邮箱、电话或外部表单地址，应用仅展示核实过的官方页面。

## 候选召回与运行范围

已确认自由案情的实时分析根据结构化字段及叙述关键词召回最多6个候选；没有相应命中信号时可为0，模型可以全部排除。词语出现可能包含否定或旁述，不能升级为已确认身份、程序或新案事实。最终采用的案例与所引证据经过归属检查，未采用的候选不会自动成为结果来源。

当前没有接入联网`web_search`，不会在分析时寻找最新法律或个案进展。Sol作为后续联网检索接入的模型选项，不代表工具已配置、来源已读取或当前结果包含实时搜索。

## 本地复现

本次实际使用Python 3.12.14与pypdf 6.10.0。可使用已有兼容Python环境；如需另建环境，使用项目虚拟环境并安装`scripts/requirements-pdf.txt`，不要求修改系统Python。只用于离线整理，不要求网站运行机器安装Python。将原始报告放到项目外或被Git忽略的`.local-sources/`目录。运行：

```sh
python scripts/extract_pdfs.py /path/to/Myriam-Bribri_June-2021_Fairness-Report.pdf /path/to/Emna-Chargui_June-2021_Fairness-Report.pdf /path/to/EN-Aigul-Utepova-Fairness-Report-April-2022.pdf --output .local-sources/extracted
python scripts/check_evidence.py --extracted .local-sources/extracted --research data/research/extracted
npm test -- scripts/data.test.ts tests/expanded-corpus.test.ts
```

上面的提取命令保留首批三份文件的使用示例；当前187条引文检查还需要全部21份来源的逐页提取，默认从`data/research/extracted`补充查找，只有三份提取文件不能完成全库验证。明确审阅过的扩展批次由`scripts/ingest_reviewed_corpus.py`合并，该脚本会写入正式JSON，不能当作只读检查执行。

再次发现重复文件时一并传入即可。脚本只输出候选逐页文字，不自动把新提取内容标成已核对或加入推荐。更新静态JSON后须重新执行检查并重新构建网站。
