# 界面 v3 · 海报式「案情陈述」

2026-10-07 第二次重构，参考 Active Maps 的视觉气质：大字号加宽字距、红色下划线标出“填进去的内容”、一屏一题。2026-10-08 去掉全部深色区块，改为奶白／米色，并加入中英双语。业务逻辑、数据、API 与会话机制未改。

旧版本完整保留：v2（现代卡片版）在 `../caselink-v2-modern`，v1（经典版）在 `../caselink-v1-classic`。

## 视觉语言（`src/app/globals.css`）

- **只用浅色**：`--paper` 奶白为页面底色，`--cream` 米色用于首屏、案情陈述、结果首屏与案例库，`--card` 近白卡片，`--band` 深一级米色用于统计条与分段控件。没有任何深色背景；遮罩层也用半透明米色加模糊。页面以 `main[data-top="dark"]` 声明首屏是米色带，页头随之延续。
- **主按钮为红色**：所有主要按钮与关闭按钮使用 `--red`（在奶白上对比度达 AA）；次要按钮为墨色描边。
- **字体**：数字与英文用 Bebas Neue（`next/font/google`，构建时自托管，浏览器不请求 Google）；中文标题用系统黑体加 .14–.6em 字距，形成海报感。
- **红色＝填空**：凡是用户答案或来自案件本身的关键词，都以信号红加下划线呈现；未知项改为琥珀色虚线，提示“这里还空着”。
- **按钮**：直角、加宽字距。

## 关键体验

| 页面 | 做法 |
|---|---|
| 首页 | 米色首屏中的“陈述卡”：在两个虚构示例间切换的填空句，底部统计条（案例、报告、行动记录、原文证据） |
| 问卷 | 一屏一题：`01 / 09` 计数 → 大号问题 → 红色下划线答案槽（实时回显所选内容）→ 编号选项列表；按数字键选择、Enter 下一步；「示例」展开两个虚构案例对此题的回答；顶部 9 段进度条可直接跳题（实线＝已明确，虚线＝待明确） |
| 程序阶段 | 横向时间线，五个阶段按先后连接 |
| 公开限制 | “对外可见度 高→低”三栏 |
| 确认页 | 米色「案情陈述」：九个答案织成一段话，每个红字可点击返回修改，未知项为琥珀虚线 |
| 结果页 | 仪表卡（目标陈述 + 统计条），下方米色分段标签切换「行动／比较／缺口」；行动卡用大号编号与顶部色条区分适用性 |
| 案例库 | 档案卡：英文姓名大字、案件填空句、统计条 |
| 菜单 | 右侧全高抽屉，大字距菜单项，底部带语言切换 |
| 语言 | 页头「中 / EN」切换，立即生效并写入 Cookie，刷新后保持 |

## 中英双语

- **界面文字**：`src/lib/i18n/ui.ts`（全部界面字符串，中英同构）、`en.ts`（选项标签）、`intake.ts`（问卷题目）。`LocaleProvider` 提供 `useI18n()`；根布局从 `caselink-locale` Cookie 读取语言，首屏即为所选语言，无闪烁。
- **案例资料**：中文原始数据与校验不变；英文译文放在 `data/i18n/en.json`，按 ID 覆盖显示（摘要、时间线、行动、结果、建议、未记载事项、冲突、证据解释、机构入口、作者）。`tests/i18n.test.ts` 检查每一条都已翻译。
- **生成结果**：分析请求携带 `locale`。规则引擎与预置示例按语言生成（中文输出与改造前逐字一致，已用 2,595 组输入比对）；实时 AI 收到同一套规则，只把输出语言改为英文，并附英文版历史资料。校验器为英文输出补充了同等的安全规则（联系方式、成功保证、推算期限、终局结果、联合国介入、公开限制、律师前提）。
- **示例**：两个虚构示例另有英文版本，英文界面载入英文示例。
- **语言不一致时**：结果页若发现方案语言与当前界面不同，会提示并提供“用当前语言重新分析”。服务端错误信息按错误码显示对应英文。
- **未覆盖**：用户自己填写的自由文本保持原样；实时 AI 的英文输出尚未用真实模型验收（需要内部访问密码与额度）。

## 可访问性与兼容

- 选项仍是原生 radio／checkbox，覆盖整行；可访问名称只取选项标题，原有 e2e 选择器不变。
- 数字键快捷选择只在焦点不在文本框时生效；Enter 不会在多行文本框、按钮和链接上触发下一步。
- 遵循 `prefers-reduced-motion`；首页示例轮播在该设置下不自动切换，鼠标悬停时暂停。

## 验证

`npm run typecheck`、`npm test`（48 项，含 9 项双语测试）、`npm run test:e2e`（5 项，含中英切换流程）、`npm run test:browser-guards` 均通过；生产构建通过并已发布；中英两种语言在 390px 宽度下所有页面均无横向滚动；英文模式下所有页面没有残留中文。

## v3.2 · 自适应整理与海报陈述合并

队友的自适应整理（v3.1）保留，v3 的海报式陈述合并回第③屏，流程为四屏：① 地区与案件（含是否与新闻或公开表达有关）→ ② 用自己的话说 → ③ 案情整理 → ④ 行动参考。细节与数据字段见 [adaptive-intake.md](adaptive-intake.md#四屏流程2026-10-09-合并)。

- 第③屏「案情整理」改为分栏的案情单（2026-10-09 根据试用反馈修改：整段原话拼接既看不出 AI 做了什么，也太重）：每栏左侧是编号与栏名，右侧是 AI 的简短概括，经过一栏用时间线。红字只用于可点开修改的概括与选择，下划线 2px、正文字体；目标和披露边界用普通正文。悬停显示原话的浮层，点击在本栏内展开编辑；琥珀色虚线是还缺的信息，点击跳到问题卡。
- 结果页沿用 v3 的海报卡片，栏目以「行动参考」开头；三类依据用同一组颜色点：绿＝已核实，琥珀＝待核实，红＝AI 整理。
- 新增组件：`AdaptiveStatement.tsx`（第③屏）、`AnalysisSubmit.tsx`（`/review` 与第③屏共用的提交、取消、重试与规则参考）。
